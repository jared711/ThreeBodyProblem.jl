Utility functions

Overview

The utility functions are all those functions that didn't fit into the other established categories.

Functions

ThreeBodyProblem.getrv — Function
getrv(rv)

Return the position and velocity vectors from rv which can be of length 2, 3, 4, or 6. This function makes it possible to deal with planar and spatial cases in a uniform way.
