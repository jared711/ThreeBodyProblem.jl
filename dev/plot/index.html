Plotting

Overview

ThreeBodyProblem.jl defines plot recipes, so once Plots.jl is loaded a System, a Body or a trajectory (a Vector{Vector{<:Real}} of states) can be passed straight to plot:

using ThreeBodyProblem, Plots
sys = earth_moon()
plot(sys)               # primaries and Lagrange points in the rotating frame
plot(sys, planar=false) # 3D

RecipesBase.apply_recipe — Method
Recipe for plotting bodies

This is a recipe for plotting bodies. It is called by the plot function. It always the body at the origin. If planar is true, it plots the body as a circle. If planar is false, it plots the body as a sphere. The radius of the body is the true dimensional radius in km. Pass in 1/sys.RUNIT as the scalar parameter to scale the body to the CR3BP.

Functions

ThreeBodyProblem.circle — Function
circle(r=1, c=[0,0,0]; n=100)

Outputs the x and y coordinates of a sphere with radius 'r', centered at 'c', and with 'n' points in each direction. To plot, just use 'plot(circle(), seriescolor=:blue, seriestype=:shape, fillalpha=0.5, lims=:auto)'

source
ThreeBodyProblem.sphere — Function
sphere(r=1, c=[0,0,0]; n=100)

Outputs the x, y, and z coordinates of a sphere with radius 'r', centered at 'c', and with 'n' points in each direction. To plot, just use 'surface(sphere(),colorbar=false,color=cgrad([:blue, :blue]),width=1,alpha=1).'

source
ThreeBodyProblem.torus — Function
torus(r=1, c=[0,0,0]; n=100)

Outputs the x, y, and z coordinates of a torus with primary radius a (radius of the circle being rotated around the z-axis) and secondary radius b (radius of the circle perpendicular to the z axis), centered at 'c', and with 'n' points in each direction. To plot the torus, just use 'surface(torus(),colorbar=false,color=cgrad([:blue, :blue]),lims=(-10,10)).'

source
ThreeBodyProblem.seczoom — Function
seczoom(sys::System; N=5)

Produces the appropriate limits for a plot to show the secondary body. N is how many radii of the secondary body the limits should reach.
